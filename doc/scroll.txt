1. INTRODUCTION                                           *scroll-introduction*

scroll.nvim draws scrollbars in the style of VS Code, overlaid on the window
edges:

- a vertical bar, which doubles as an overview ruler marking diagnostics, git
  changes and search matches across the whole buffer;
- a horizontal bar, shown when 'wrap' is off and lines run past the edge;
- an optional minimap in the buffer's colours, with a git change gutter.

Bars can be clicked and dragged, and hide when idle by default.

==============================================================================
2. SETUP                                                         *scroll-setup*

Installing the plugin is enough: it sets itself up with the defaults once
Nvim has started. Call |scroll.setup()| only to change options: >lua

    require("scroll").setup({ minimap = true })
<
With lazy.nvim: >lua

    { "mihovilrak/scroll.nvim", opts = { minimap = true } }
<
Mouse support needs 'mouse' to include normal mode (the default "a" does).

3. OPTIONS                                                     *scroll-options*

Pass a table to |scroll.setup()|; omitted keys keep their defaults. The
`vertical`, `horizontal`, `marks` and `minimap` sections, and each source under
`marks`, can be given as a bare boolean: `minimap = true` means
`minimap = { enabled = true }`. >lua

    require("scroll").setup({
      minimap = true,
      marks = { git = false },
      marks = { diagnostics = { severity = { min = vim.diagnostic.severity.WARN } } },
    })
<
                                                       *scroll-option-enabled*
enabled ~
    Boolean, default `true`. `false` keeps the bars off until |scroll.enable()|.

                                                      *scroll-option-vertical*
vertical ~
    `enabled`     Boolean, default `true`.
    `width`       Columns, default `1`. With 2 or more, git marks get their own
                  column.
    `char`        Thumb glyph, default `"█"`.
    `track_char`  Track glyph, default `"│"`. Use `" "` for an invisible track.

                                                    *scroll-option-horizontal*
horizontal ~
    `enabled`     Boolean, default `true`.
    `height`      Rows, default `1`.
    `char`        Thumb glyph, default `"▄"`: half a cell tall, which is
                  about as thick as the one-column vertical thumb. Use `"█"`
                  for a full cell, and with `height` above 1.
    `track_char`  Track glyph, default `"─"`.

Where the two tracks meet, the vertical track ends in a box-drawing joint
(`┘` for the default glyphs) when both bars are one cell thick.

                                                         *scroll-option-marks*
marks ~
    Overview ruler on the vertical bar. When marks share a cell, the most
    severe wins: error > warning > search > info > hint > git.

    `enabled`                   Boolean, default `true`.
    `diagnostics.enabled`       Boolean, default `true`.
    `diagnostics.char`          Default `"━"`.
    `diagnostics.severity`      Filter passed to |vim.diagnostic.get()|,
                                default `nil` (all).
    `git.enabled`               Boolean, default `true`.
    `git.char`                  Default `"▌"`.
    `git.max_lines`             Default `20000`. Without gitsigns, buffers
                                larger than this are not diffed.
    `git.debounce`              Milliseconds, default `200`. Without
                                gitsigns, the delay after an edit before
                                re-diffing.
    `search.enabled`            Boolean, default `true`. Marks lines matching
                                the last search pattern while 'hlsearch' is
                                highlighting it.
    `search.char`               Default `"━"`.

    Git hunks come from gitsigns.nvim when it is attached to the buffer.
    Otherwise the buffer is diffed against its git index version, which is
    refreshed on write and on |FocusGained|.

                                                       *scroll-option-minimap*
minimap ~
    `enabled`           Boolean, default `false`.
    `width`             Columns including the git gutter, default `14`.
    `columns_per_dot`   Text columns per braille dot column, default `3`.
                        Each braille cell covers 4 buffer lines. `2` keeps
                        the text's proportions but needs a wider map.
    `colors`            Boolean, default `true`. Colour each cell with the
                        highlight group covering most of its text, from
                        treesitter or else |:syntax|. `false` draws the
                        whole map in `ScrollMinimap`.
    `min_window_width`  Default `80`. Narrower windows get no minimap.
    `git`               Boolean, default `true`. Show the git gutter.
    `git_char`          Default `"▎"`.
    `winblend`          Default `0`.
    `autohide`          Boolean, default `false`. Hide along with the bars
                        under |scroll-option-visibility|.

    Click or drag on the minimap to centre the window there.

                                                    *scroll-option-visibility*
visibility ~
    `"auto"` (default)  Show on activity, hide after `hide_delay` ms.
    `"always"`          Show whenever the content overflows.
    `"hover"`           Show while the pointer is over a bar. Needs
                        'mousemoveevent'.

hide_delay ~
    Milliseconds, default `1000`.

winblend ~
    Transparency of the bars, 0-100, default `30`.

zindex ~
    Default `40`: above window text, below completion menus and most popups.

mouse ~
    Boolean, default `true`. Click-to-jump and dragging.

excluded_filetypes ~
    Default `{ "help", "qf", "NvimTree", "neo-tree", "TelescopePrompt",
    "lazy", "mason" }`.

excluded_buftypes ~
    Default `{ "terminal", "prompt", "nofile", "quickfix" }`.

min_width, min_height ~
    Defaults `20` and `5`. Smaller windows get no bars.

exact_measure_max_lines ~
    Default `10000`. A single jump across more lines than this places the
    thumb by interpolation instead of exact measurement.

==============================================================================
4. COMMANDS                                                   *scroll-commands*

:ScrollToggle                                                   *:ScrollToggle*
    Toggle the bars.

:ScrollEnable                                                   *:ScrollEnable*
:ScrollDisable                                                 *:ScrollDisable*
    Enable or disable the bars.

:ScrollRefresh                                                 *:ScrollRefresh*
    Redraw the bars now, re-reading the highlight groups.

:ScrollMinimapToggle                                     *:ScrollMinimapToggle*
    Toggle the minimap.

==============================================================================
5. LUA API                                                         *scroll-api*

scroll.setup({opts})                                          *scroll.setup()*
    Configure and enable. Optional; see |scroll-setup|. Calling it again
    replaces the options. See |scroll-options|.

scroll.enable()                                              *scroll.enable()*
scroll.disable()                                            *scroll.disable()*
scroll.toggle()                                              *scroll.toggle()*
    Enable, disable or toggle the bars.

scroll.refresh()                                            *scroll.refresh()*
    Redraw the bars now, re-reading the highlight groups.

scroll.toggle_minimap({on})                          *scroll.toggle_minimap()*
    Toggle the minimap, or force it on or off with a boolean {on}.

scroll.is_enabled()                                      *scroll.is_enabled()*
    Whether the bars are enabled.

==============================================================================
6. HIGHLIGHTS                                               *scroll-highlights*

All groups are defined with `default = true`, so your own definitions win.

ScrollTrack             Track. Links to |hl-PmenuSbar|.
ScrollThumb             Thumb. Links to |hl-PmenuThumb|. The glyph is drawn
                        in its foreground (the |hl-Normal| foreground if it
                        has none) over the track's background.
ScrollThumbHover        Thumb under the pointer.
ScrollMarkError         Diagnostic marks. Link to the matching
ScrollMarkWarn          `Diagnostic*` groups.
ScrollMarkInfo
ScrollMarkHint
ScrollMarkSearch        Search marks. Foreground taken from |hl-Search|.
ScrollMarkAdd           Git marks. Link to `GitSigns*` when the
ScrollMarkChange        colorscheme defines them, otherwise to
ScrollMarkDelete        `Added`, `Changed` and `Removed`.
ScrollMinimap           Minimap, and its dots when `colors` is off. Links
                        to |hl-NormalFloat|.
ScrollMinimapViewport   Visible region in the minimap. Links to |hl-Visual|.

==============================================================================
7. LIMITATIONS                                             *scroll-limitations*

- Horizontal width ignores concealed text and inline virtual text.
- The minimap ignores folds and wrapping, and counts double-width
  characters as one column.
- Fold changes made away from the visible lines (for example `:100,400fold`
  while viewing the top of the buffer) are noticed at the next edit or
  option change.
- Neovim keeps the cursor on screen, so dragging a bar moves the cursor into
  the new view.
